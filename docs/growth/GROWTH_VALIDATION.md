# Growth Validation

## Must pass before private beta invites

1. **One phone entry** — create intro with phone → Ready-to-Share WhatsApp opens with that number prefilled.  
2. **Personalized SMS/WhatsApp body** includes inviter name + relationship + preview link.  
3. **WhatsApp link preview** shows title/description/image for a fresh invite.  
4. **Oversize file** (≥101 MB) shows friendly error with **zero** network upload.  
5. **Background upload** — leave create-story during upload; dock remains; Ready-to-Share appears at 100%.  
6. **Invite accept** — new user lands and can see the introduction story.  
7. **Voice note story** plays fully before auto-advance.
